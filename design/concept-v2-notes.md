# Undertopia — Concept v2 작업 노트

> **Status**: 브레인스토밍 중 (2026-11-09 시작)
> **Supersedes**: `design/game-brief.md`의 인물·구성·서사 (확정되면 브리프를 새로 씀)
> 확정된 결정만 적는다. 미정은 "열린 질문"에 둔다.

## 남기는 것
- 제목: 언더토피아
- 배경: 지하낙원 (땅 아래의 낙원). 낙원이 생긴 이유 등 그 밖의 설정은 새로 정한다.

## 마을
- 지하낙원은 **아이의 고향 마을**을 아이의 인식대로 다시 만든 곳이다. 주민들은 실제 그 마을 사람들이다.
- 땅 위의 원래 마을은 **기근과 질병**으로 무너져 가고 있었다(촌장 시트 참고).
- 어느 시점에 마을이 **봉쇄**되어, 밖에 나간 사람은 돌아오지 못했다(여관 주인 시트 참고).
- 봉쇄는 **바깥의 명령**이었다. 마을 사람들은 버려졌다고 느꼈다.

## 확정된 결정

### 대전제 (세계의 규칙)
1. 마을은 **아이의 소망**으로 생겨났다.
2. 이 과정에서 주민들은 **아이가 인지하고 인식하던 모습**으로 변했다. 동물 형태는 아이 눈에 그 사람이 어떻게 보였는지를 나타낸다.
3. 아이가 **확실히 구분할 수 있는 사람**은 둘 중 하나다.
   - 자아가 있는 **주민**으로 존재한다.
   - 아이가 그 사람의 **죽음을 인지**하고 있으면 **아예 존재하지 않는다**. 아이의 부모가 그렇다.
4. 아이가 **제대로 인지하지 못한 사람**은 **말로(hollow)**로 존재한다. 관심이 없었거나, 지나가다 얼굴만 봤거나, 이름만 들어 본 정도의 사람이다. 자아 없이 존재만 한다.

### 주인공
- 이 마을의 존재를 알고 "뒤틀림"을 조사하러 온 **조사관**이다.
- 정체를 숨기지 않는다. 기억 상실이나 위장 같은 장치도 없다.
- 소속이나 뒷배경은 따로 두지 않는다. "조사하러 온 조사관", 그게 전부다.
- **조사하는 느낌**은 플레이 행위로 낸다. 탐험하며 단서를 모으고, 주민마다 있는 **단서 노트**를 맞춰 가거나 분석한다.

### 아이
- **마을의 근원**이다. 아이의 소망이 뒤틀려 이 마을이 생겼다.
- **아이의 가족은 모두 죽었다.** 이 사건이 마을이 생겨난 계기다.
- 아이는 부모가 죽었다는 것을 확실히 인식한다. 그래서 부모는 말로로도 마을에 없다(대전제 3).

## 캐릭터 시트

### 1. 촌장 (거북)
| 항목 | 내용 |
|---|---|
| 사람이었을 때 | 실제로 **마을의 촌장**이었다. |
| 소망 | **아무것도 변하지 않기.** |
| 아는 정도 | 마을의 정체와 아이에 대해 **모든 것을 알고 숨긴다.** |
| 이야기 위치 | 조사관이 **가장 먼저 만나는 주민**이지만, **대면(전투)은 가장 마지막**이다. |
| 트라우마 | **사라져 가는 마을.** 마을은 기근과 질병으로 무너져 가고 있었다. |
| 뒤틀림 | **멈춰 버린 시간.** 멈춘 것은 **촌장 자신의 시간**이다. 촌장이 폭주하면 이 멈춤이 **마을 전역으로 옮겨 가**, 매일이 반복되는 뒤틀림으로 발현된다(촌장의 능력). 그 전까지 마을의 날짜는 흐른다. |
| 트리거 | 마을의 정체를 알아 가려는 조사관. 폭주는 **마지막 시점**에 시작된다. 조사관이 아이의 소망이 모든 사건의 근원임을 알고 아이에게 향할 때, 촌장이 그것을 막아서며 대면이 시작된다. |
| 아이와의 관계 | **맡아 준 어른.** 가족을 잃은 아이를 촌장이 맡아 돌봤다. |
| 단서 | **멈춘 시계들**: 촌장 주변(집, 마을회관 등)의 시계가 모두 같은 시각에 멈춰 있다. 그날이 무슨 날인지 추적한다.<br>**마을 기록부**: 촌장의 장부. 찢겨 나가거나 덧칠된 장이 있고, 식량 배급과 사망자 명단이 남아 있다.<br>**반복되는 대사**: 늘 같은 말로 조사관을 맞는다. 문구가 조금씩 어긋날 때가 단서다. |
| 대면 방식 | 미정 (캐릭터 서사를 다 정한 뒤 설계) |

### 2. 여관 주인 (양)
| 항목 | 내용 |
|---|---|
| 사람이었을 때 | 실제 마을의 **여관 주인**. |
| 트라우마 | 자기 **생일날**, 남편과 딸(여자아이 1명)이 선물을 준비하러 마을 밖에 나갔다. 그사이 **마을이 봉쇄되어** 돌아오지 못하고 객사했다. "나가지 못하게 막았어야 했다"며 자기 책임으로 여기는 **죄책감**을 안고 있다. |
| 아이와의 관계 | **따뜻한 엄마 같은 사람.** |
| 소망 | **아무도 나가지 않기.** 그때 막지 못한 것을 이번에는 막겠다는 바람이다. |
| 뒤틀림 | **나갈 수 없는 여관.** 들어온 손님은 나갈 수 없다. 문을 열면 다시 복도가 나오고, 방마다 머물러 사는 말로들이 있다. |
| 트리거 | **자기 생일날, 누군가 여관을 떠나려 할 때** 폭주한다. |
| 아는 정도 | 가족이 죽은 것을 **알고 있지만**, 그 이야기가 나오면 **화제를 돌린다.** |
| 단서 | **세 인분의 식탁**: 매일 저녁 세 사람 몫이 차려지고, 두 자리는 손도 대지 않은 채 식어 있다.<br>**못 받은 선물**: 가족이 준비하던 생일 선물. 마을 밖 또는 마을 끝 어딘가에 남아 있다. |
| 대면 방식 | 미정 (캐릭터 서사를 다 정한 뒤 설계) |

### 3. 잡화점 주인 (고양이)
| 항목 | 내용 |
|---|---|
| 사람이었을 때 | 실제 마을의 **잡화점 주인**. |
| 컨셉 | **깐깐한 등가교환.** 동일한 가치, "가치"라는 것 자체. |
| 트라우마 | 봉쇄가 시작되자 자기가 가진 물자를 필요한 사람들에게 **아낌없이 내주었다.** 그런데 정작 자기 가족이 아팠을 때는 **아무 도움도 받지 못했다.** 약을 구하지 못해 가족을 잃었고, 그 뒤로 **혼자 버텼다.** |
| 아이와의 관계 | **사탕 주는 어른.** |
| 소망 | **모두가 공평하기.** |
| 뒤틀림 | **무엇이든 값이 있는 가게.** 기억, 목소리, 이름, 시간까지 값을 매겨 사고판다. |
| 트리거 | **자기가 받지 못한 값과 마주할 때.** 조사관이 단서로 봉쇄 때의 옛 장부(누구에게 무엇을 내주었는지)를 맞추면, 마을이 그에게 진 빚이 계산된다. 돌아온 것은 하나도 없었고 가족의 약조차 받지 못했다. "모두가 공평하기"를 바라는 그에게 가장 불공평한 대우를 받은 사람이 자기 자신이었다는 사실이 드러나며 저울이 무너지고 폭주한다. (잠정) |
| 구원 방향 (메모) | 아이에게 준 **공짜 사탕**. 값을 받지 않고 준 것도 헛되지 않았다는 것. 대면 방식 설계 때 다룬다. |
| 아는 정도 | 다 **알지만 장사로 덮는다.** "그건 얼마에 알려 주지"라며 과거에도 값을 매긴다. |
| 단서 | **옛 장부 조각**: 봉쇄 때 누구에게 무엇을 내주었는지 적힌 장부. 마을 곳곳에 흩어져 있고, 트리거의 핵심이다.<br>**기묘한 가격표**: "여관 주인의 웃음: 품절", "농부의 목소리: 3개"처럼 주민들이 자기를 팔아 버린 흔적.<br>**사탕 병**: 계산대 옆 사탕 병에만 가격표가 없다. |
| 대면 방식 | 미정 (캐릭터 서사를 다 정한 뒤 설계) |

### 4. 약사 (고슴도치)
| 항목 | 내용 |
|---|---|
| 사람이었을 때 | 실제 마을의 **약사**. |
| 트라우마 | **가짜 약.** 봉쇄로 약이 떨어지자, 사람들을 안심시키려고 설탕물이나 가짜 약을 나눠 주었다. 사람들은 나을 거라 믿으며 죽어 갔다. |
| 소망 | **아무도 아프지 않기.** |
| 아이와의 관계 | **따끔하지만 다정한 어른.** 쓴 약을 주지만 다정했다. |
| 뒤틀림 | **아무도 고통을 느끼지 못하고, 결국 아무것도 느끼지 못하게 된다.** |
| 트리거 | **가짜 약이 드러날 때.** |
| 아는 정도 | 다 **알고 있지만**, 그것이 **올바른 선택**이었다고 믿는다. |
| 다른 주민과의 연결 | **잡화점 주인**이 가족의 약을 받지 못한 것은 약사가 **가짜 약에 대한 죄책감** 때문에 그에게 약을 내주지 못했기 때문이다. 모든 것을 내준 사람에게만은 가짜 약을 건넬 수 없어 아무것도 주지 못했다. "올바른 선택"이라는 믿음에 스스로 만든 단 하나의 예외다. |
| 단서 | **조제 기록**: 봉쇄 이후 성분 칸이 "설탕, 물"로 바뀌어 있다. 잡화점 주인의 이름만 조제 없이 지워져 있다.<br>**감사 편지**: "약 덕분에 편히 갔습니다"라는 유족들의 편지 다발. 우체부(올빼미)와 이어질 수 있다.<br>**진짜 약 한 병**: 약사가 끝까지 쓰지 않고 간직한 마지막 진짜 약. 누구를 위한 것이었는지는 미정이다. |
| 대면 방식 | 미정 (캐릭터 서사를 다 정한 뒤 설계) |

### 5. 제빵사 (곰)
| 항목 | 내용 |
|---|---|
| 사람이었을 때 | 실제 마을의 **제빵사**. |
| 트라우마 | 빵을 만들 **재료가 떨어져**, 사람들이 굶어 죽어 가는 것을 (간접적으로) 지켜봐 왔다. |
| 소망 | **모두 배부르기.** |
| 아이와의 관계 | **마지막 빵을 준 사람.** 기근 때 아이에게 마지막 빵을 주었다. 아이가 살아남은 이유 중 하나다. |
| 뒤틀림 | **멈추지 않는 오븐.** 오븐이 꺼지지 않고 빵이 넘쳐 나와 거리를 덮는다. 주민들은 배가 불러도 거절하지 못하고 계속 먹는다. |
| 트리거 | **빵을 거절할 때.** |
| 아는 정도 | **기근을 잊었다.** 빵은 언제나 있었다고 믿는다. |
| 단서 | **빈 밀가루 포대**: 빵은 넘치는데 창고의 밀가루 포대는 모두 비어 있다. 그럼 이 빵은 무엇으로 만들었을까?<br>**주문 장부**: 주문 칸에 매일 똑같은 이름들이 적혀 있다. 대부분 말로가 된 사람들이다.<br>**농부의 편지**: "올해는 밀을 보낼 수 없을 것 같네"라는 농부(두더지)의 쪽지. |
| 대면 방식 | 미정 (캐릭터 서사를 다 정한 뒤 설계) |

### 주민
- 원래는 **사람**이었다. 마을이 생기면서 **동물 형태로 변했다**.
- 주요 주민(뒤틀림을 풀어야 하는 인물)은 **10명**이다. 그중 둘은 **쌍둥이**라 함께 대면하므로 **대면(전투)은 9번**이다.
- 주민마다 **서사, 배경, 트라우마, 트리거**를 먼저 정한다.

### 대면 방식 (전투)
- 각 캐릭터의 서사, 배경, 트라우마, 트리거를 정한 **뒤에** 그에 맞춰 설계한다. 기존 탄막 + 마음 게이지 설계(`design/gdd/combat-system.md`)는 확정 전까지 참고용이다.

### 뒤틀림
- 이 마을이 생겨난 이유이자, 마을 주민들이 변한 원인이다.
- 주민 각자의 소망이 기괴하게 번져 가는 현상이다.

### 엔딩
- 플레이어의 선택과 실패에 따라 갈린다(멀티 엔딩).
- **배드 엔딩**: 주인공이 마을에 동화되어, 다른 주민처럼 뒤틀린 채 살아간다.
- **노멀 엔딩**: 아이를 구원하고 마을을 없앤 뒤 끝난다.
- **트루 엔딩**: 모든 주민이 **사람으로 돌아간다**. 조건은 미정.

## 열린 질문
- 배드 엔딩으로 가는 실패 조건
- 트루 엔딩 조건
- 주민 10명의 정체(동물, 원래 직업이나 정체, 서사, 트라우마, 트리거)
- 아이의 이야기: 무엇을 소망했고, 왜 뒤틀렸는가
- 아이의 가족이 어떻게 죽었는가 (기근? 질병? 다른 원인?)
- 마을의 시간이 멈춘 "그날"은 어떤 날인가 (촌장의 멈춘 시계 단서와 연결)
- 주민별 대면(전투) 방식
